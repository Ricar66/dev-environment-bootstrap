# Perfis de desenvolvimento

Os perfis permitem instalar apenas as ferramentas mais úteis para cada tipo de ambiente.

## Essential

Base para qualquer pessoa desenvolvedora:

- Git
- VS Code
- terminal e PowerShell no Windows
- GitHub CLI
- utilitários básicos

## Frontend

Inclui o Essential e adiciona:

- Node.js LTS
- npm
- Postman

## Backend

Inclui ferramentas para APIs e serviços:

- Essential
- Node.js LTS
- Python
- Postman
- Docker

## FullStack

Combina Frontend + Backend e habilita Docker/WSL no Windows.

## DataSQL

Voltado a Python, SQL e bancos:

- Essential
- Python
- DBeaver no Windows
- clientes PostgreSQL/MySQL no Ubuntu
- SQLite
- Docker para bancos isolados

## DevOps

Voltado a containers e ambiente:

- Essential
- Docker
- WSL no Windows
- SSH e ferramentas de rede no Ubuntu

## Observação

Os perfis são um ponto de partida. O objetivo do projeto não é instalar toda ferramenta existente, e sim oferecer uma base útil, previsível e fácil de diagnosticar.
