# Código de Conduta

O Super Dev Kit busca manter uma comunidade técnica acolhedora, objetiva e segura para pessoas com diferentes níveis de experiência.

## Esperamos

- respeito em issues, pull requests e discussões;
- críticas focadas no código, comportamento ou decisão técnica;
- abertura para explicar contexto a quem está aprendendo;
- feedback específico e acionável;
- cuidado para não publicar dados sensíveis;
- colaboração de boa-fé.

## Não aceitamos

- assédio, intimidação ou ataques pessoais;
- discriminação ou linguagem depreciativa;
- exposição de dados pessoais ou credenciais;
- spam;
- pressão para executar código inseguro;
- comportamento repetidamente hostil que impeça colaboração técnica.

## Discussões técnicas

Discordar faz parte do desenvolvimento. Ao discordar, descreva o comportamento observado, mostre evidências reproduzíveis, proponha uma alternativa e separe preferência pessoal de requisito do projeto.

## Segurança

Nunca peça a outra pessoa que publique tokens, senhas, chaves privadas, certificados internos ou dados de clientes/instituições.

## Aplicação

Problemas de conduta podem resultar em edição ou remoção de conteúdo, encerramento de discussão ou bloqueio de participação, conforme gravidade e repetição.

Quando possível, reportes sensíveis devem usar os canais privados disponibilizados pelo mantenedor no GitHub.
