# Super Dev Kit v1.0.0

Primeira release estável do Super Dev Kit.

## O que é

Uma CLI multiplataforma para preparar, diagnosticar e reproduzir ambientes de desenvolvimento em Windows e Ubuntu/Linux.

## Destaques

- CLI devkit;
- suporte a CMD, PowerShell e Bash;
- perfis Essential, Frontend, Backend, Full Stack, Data/SQL e DevOps;
- stacks reutilizáveis;
- Dev Doctor;
- templates de projeto;
- Dev Containers opcionais;
- version manager adapters;
- manifesto local;
- export/import de ambiente;
- detecção de drift;
- backup e inventário;
- cleanup controlado;
- certificado corporativo opcional;
- saída JSON para automação;
- documentação pública e manual completo.

## Primeiros passos

~~~text
git clone https://github.com/Ricar66/dev-environment-bootstrap.git
cd dev-environment-bootstrap
~~~

Windows:

~~~text
devkit.cmd setup fullstack --dry-run
devkit.cmd setup fullstack
devkit.cmd doctor
~~~

Ubuntu/Linux:

~~~text
bash devkit.sh setup fullstack --dry-run
bash devkit.sh setup fullstack
bash devkit.sh doctor
~~~
