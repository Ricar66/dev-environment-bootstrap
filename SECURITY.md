# Política de Segurança

## Não publique segredos

Nunca faça commit de:

- tokens;
- senhas;
- chaves privadas;
- arquivos `.env` com credenciais;
- certificados internos não destinados à distribuição pública;
- dados de clientes, empresas ou instituições.

## Vulnerabilidades

Se encontrar uma vulnerabilidade, evite publicar credenciais, provas de conceito destrutivas ou informações sensíveis em uma issue pública.

Abra uma discussão/issue apenas com informações seguras ou use o canal privado disponibilizado pelo mantenedor no GitHub, quando houver.
