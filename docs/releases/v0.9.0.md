# Super Dev Kit v0.9.0 — Public Readiness

A v0.9 prepara o Super Dev Kit para receber usuários e contribuidores fora do contexto original do projeto.

## Destaques

- README reorganizado para onboarding rápido;
- arquitetura pública documentada;
- FAQ e troubleshooting consolidados;
- matriz de suporte;
- exemplos de automação com JSON;
- CONTRIBUTING ampliado;
- Código de Conduta;
- templates melhores para bugs, features e pull requests;
- guias para criar stacks, templates e adapters;
- validação automática de links locais e UTF-8;
- smoke tests em Windows PowerShell 5.1, PowerShell 7, CMD e Bash;
- teste de onboarding em Ubuntu 24.04 descartável;
- material de lançamento preparado para GitHub, LinkedIn e artigos.

## Para quem está chegando agora

~~~text
git clone https://github.com/Ricar66/dev-environment-bootstrap.git
cd dev-environment-bootstrap
~~~

Windows:

~~~text
devkit.cmd setup fullstack --dry-run
devkit.cmd doctor
~~~

Linux:

~~~text
bash devkit.sh setup fullstack --dry-run
bash devkit.sh doctor
~~~

## Filosofia

A v0.9 não busca adicionar grandes features. Ela prioriza clareza, confiabilidade, contribuição e apresentação pública antes da v1.0.

## Próximo passo

A v1.0 será focada em estabilidade, compatibilidade formal, releases versionadas e política de breaking changes.
